# D 模块前端使用说明

本文档对应分工 PDF 中 D 的 non-coding 交付物，说明如何使用 Web 前端完成登录、检索、条件筛选、结果查看、可视化、数据集管理和索引管理。

## 1. 启动前准备

确认依赖已安装：

```powershell
cd D:\SE_Final\nksoft_proj
pip install -r requirements.txt
```

确认数据文件存在：

```text
data/sample.h5ad
```

配置 SQLite 数据库路径：

```powershell
$env:NK_DB_PATH="D:\SE_Final\nksoft_proj\database\frontend_runtime2.db"
```

启动服务：

```powershell
python app.py
```

打开浏览器：

```text
http://127.0.0.1:5000
```

## 2. 登录与注册

### 2.1 登录

页面初始只显示账号和密码两个输入框。

默认管理员：

```text
账号：admin
密码：admin
```

登录逻辑：

1. 前端提交账号和密码到 `POST /api/login`。
2. 后端查询 SQLite 的 `users` 表。
3. 如果账号不存在，前端弹窗提示“需要先注册”。
4. 如果密码错误，前端显示“密码错误，请重新输入”。
5. 如果登录成功，后端返回用户 `role`。
6. 前端根据 `role=user/admin` 自动进入普通用户或管理员界面。

### 2.2 注册

点击“注册新账号”进入注册界面。注册普通用户会调用：

```text
POST /api/register
```

注册成功后自动返回登录页面，并填入刚注册的账号。管理员账号只能由已登录管理员在后台创建。

## 3. 查看系统状态

登录后会显示“系统状态”区域，展示：

- 数据是否加载完成。
- 当前数据路径。
- 细胞数量。
- PCA 向量维度。
- 当前索引类型。
- 索引构建耗时。

如果刚启动时显示：

```text
loaded: false
initializing: true
```

表示后台仍在加载 `.h5ad` 和索引。等待状态变为 `loaded: true` 后即可检索。

## 4. 三种检索方式

前端“细胞检索”区域支持三种方式。

### 4.1 按细胞编号

选择“按细胞编号”，输入：

```text
4
```

点击“开始检索”。

### 4.2 按真实 cell_id

选择“按细胞 ID”，输入：

```text
AAACCTGTCATAAAGG-1_2
```

点击“开始检索”。

### 4.3 按自定义 PCA 向量

选择“按自定义向量”，输入 30 维逗号分隔向量，例如：

```text
2.2930813,27.493592,2.5815551,7.6082674,-3.4993581,-2.0830045,-0.21141971,-3.4404183,2.0747137,-12.857695,-2.2665378,0.11963992,1.7292324,1.487157,0.3431908,0.58974461,3.847756,10.807111,0.65465985,-2.8503491,1.6966989,0.60788797,0.37084127,1.0063659,-0.20603992,-0.034288398,0.15471178,1.2135784,-0.16843452,-0.70989546
```

点击“开始检索”。

## 5. Top-K 设置

在 `Top-K` 输入框中设置返回结果数量，例如：

```text
10
```

后端会通过 `Settings.max_top_k` 限制最大返回数量，避免一次返回过多结果。

## 6. 条件筛选

条件筛选区域字段来自：

```text
GET /api/metadata
```

使用步骤：

1. 等待数据加载完成。
2. 点击“刷新”或完成一次检索，字段下拉框会自动填充。
3. 选择字段，例如 `cell_type`。
4. 输入筛选值，例如 `T cell`。
5. 点击“添加”。
6. 再点击“开始检索”。

注意：筛选值需要与 metadata 中的值完全一致。

常用测试值：

```text
cell_type = T cell
cell_type = hepatocyte
donor_id = C102
sex = female
```

## 7. 查看检索结果

结果表格字段包括：

| 字段 | 说明 |
|---|---|
| 排名 | Top-K 排名 |
| 细胞编号 | `cell_index` |
| 细胞 ID | `cell_id` |
| 相似度 | `score` |
| 元信息 | metadata 前若干字段 |

结果区域也会显示：

- 返回结果数量。
- 当前索引类型。
- 查询耗时 `query_time_ms`。

## 8. PCA / UMAP 可视化

可视化区域由 `static/js/visualization.js` 实现，数据来自：

```text
GET /api/embedding?basis=umap&color_by=cell_type
```

功能：

- 支持 UMAP 和 PCA 二维坐标。
- 支持按 metadata 字段着色。
- 鼠标悬浮显示 `cell_id`、`cell_index`、当前着色字段。
- 检索后自动高亮 Top-K 结果。
- 按细胞编号或 cell_id 查询时，会额外高亮查询细胞。

使用步骤：

1. 登录并等待 `loaded: true`。
2. 在可视化区域选择 `UMAP` 或 `PCA`。
3. 选择着色字段，例如 `cell_type`。
4. 点击“加载图”。
5. 执行任意检索，图中会高亮结果点。

## 9. 管理员数据集管理

管理员登录后可见“管理员”区域。

数据集功能：

- 查看数据集列表。
- 添加数据集。
- 删除数据集。
- 切换 active 数据集记录。

添加数据集要求：

- 路径必须存在。
- 文件后缀必须是 `.h5ad`。
- 数据集名称不能重复。

注意：当前切换 active 数据集只更新 SQLite 记录。实际搜索服务启动时仍根据 `SC_DATA_PATH` 或 `data/sample.h5ad` 加载数据，切换后建议重启服务或后续扩展 `/api/load-data`。

## 10. 管理员索引管理

管理员可选择索引类型：

```text
HNSW
Flat
IVF
```

点击“重建当前索引”会调用：

```text
POST /api/rebuild-index
```

成功后显示：

- 索引类型。
- 索引构建耗时。
- 状态区域中的 `build_time_ms`。

## 11. 常见问题

### 11.1 字段筛选下拉框为空

原因：前端登录时数据还未加载完成，`/api/metadata` 早于数据加载执行。

处理：

1. 等待系统状态 `loaded: true`。
2. 点击“刷新”。
3. 或执行一次检索，前端会自动重试加载 metadata。

### 11.2 `Unexpected token 'N'`

原因：metadata 中有 `NaN`，旧版本后端返回了非法 JSON。

当前已修复：后端会把 `NaN` 和无穷值转为 JSON `null`。

### 11.3 启动很久没有检索结果

原因：首次读取大 `.h5ad` 或构建索引耗时较长。

当前实现会先启动前端，再后台初始化。等待状态变为 `loaded: true`。
